## Protocol

x402 turns HTTP 402 into a machine-payable handshake. Server returns payment terms; client attaches a signed payload; facilitator verifies and settles (typically USDC). V2 headers: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE. Open Apache-2.0 standard; Linux Foundation x402 Foundation operational 14 Jul 2026.
