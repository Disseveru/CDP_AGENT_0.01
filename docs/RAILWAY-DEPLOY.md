# Deploy AgentWire on Railway (new account)

Railway keeps AgentWire **always on** — no cold starts like Render's free tier. Production config sets `sleepApplication: false` in `gas-oracle-mcp/railway.json`.

## What you need (one time)

| Item | Where |
| --- | --- |
| Railway account | [railway.com](https://railway.com) |
| GitHub connected | Railway → Account Settings → link GitHub |
| CDP API keys | [portal.cdp.coinbase.com](https://portal.cdp.coinbase.com) |
| Railway API token | [railway.com/account/tokens](https://railway.com/account/tokens) → paste into Cursor secrets as `RAILWAY_TOKEN` |

## Quick setup (operator + agent)

### 1. Create the Railway project (dashboard — ~2 minutes)

1. Railway → **New Project** → **Deploy from GitHub repo**
2. Select **`Disseveru/CDP_AGENT_0.01`**
3. Railway creates a service from the root `railway.toml` (builds `gas-oracle-mcp/` automatically)
4. Wait for the first deploy to finish (it may fail until Postgres/CDP vars are set — that's normal)

### 2. Add Postgres + Redis (dashboard)

In the same project:

1. **+ New** → **Database** → **Add PostgreSQL** (name it `Postgres`)
2. **+ New** → **Database** → **Add Redis** (name it `Redis`)

### 3. Wire everything (agent runs this)

Once `RAILWAY_TOKEN` is in Cursor secrets:

```bash
npm run railway:init -- --redeploy
```

This script:

- Finds your MCP service, Postgres, and Redis
- Mounts a persistent volume at `/app/gas-oracle-mcp/data`
- Sets `DATABASE_URL`, `REDIS_URL`, `NETWORK=base`, facilitator URL, etc.
- Copies CDP keys from Cursor secrets when present
- Generates a public `*.up.railway.app` domain if missing
- Writes `.cursor/railway-project.json` (project/service IDs for other scripts)

**Brand-new account with no project yet:**

```bash
npm run railway:init -- --create-project --redeploy
```

### 4. Cursor MCP connection

```bash
npm run setup:cursor-mcp -- https://YOUR-DOMAIN.up.railway.app
RAILWAY_TOKEN=... npm run railway:sync-mcp-key
npm run verify:cursor-mcp
```

Restart Cursor → **Settings → MCP** → enable **gas-oracle-mcp**.

### 5. Sync GitHub Actions secrets

```bash
npm run github:sync-secrets -- --apply
```

This copies `RAILWAY_TOKEN`, `MCP_API_KEY`, CDP keys, etc. so the daily **Production health** workflow monitors Railway (not Render).

## Verify production

```bash
curl https://YOUR-DOMAIN.up.railway.app/health
curl https://YOUR-DOMAIN.up.railway.app/ready
npm run railway:diagnose
npm run repo:health-report
```

Expected:

- `/health` → `status: ok`, `runtimeStatus: ready`, Postgres + Redis connected
- `/ready` → `paymentsAvailable: true`
- `/sse` without auth → `401`

## Railway project layout

| Service | Role |
| --- | --- |
| **gas-oracle-mcp** (or repo name) | AgentWire MCP server |
| **Postgres** | Durable inbox storage (`DATABASE_URL=${{Postgres.DATABASE_URL}}`) |
| **Redis** | Webhook rate limiting (private `REDIS_URL`) |
| **Volume** | File-backed fallback at `/app/gas-oracle-mcp/data` |

## Required environment variables (MCP service)

| Variable | Value |
| --- | --- |
| `CDP_API_KEY` | CDP API key ID |
| `CDP_PRIVATE_KEY` | CDP API secret (PEM; use `\n` escapes on one line) |
| `CDP_WALLET_SECRET` | CDP wallet secret |
| `MCP_API_KEY` | Generated by `setup:cursor-mcp` / `railway:init` |
| `NETWORK` | `base` (mainnet USDC) |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` (set by `railway:init`) |
| `REDIS_URL` | `redis://${{Redis.RAILWAY_PRIVATE_DOMAIN}}:6379` |
| `STORAGE_BACKEND` | `postgres` |

Optional: `OPERATOR_SMS_NUMBER`, `OPERATOR_EMAIL`, `TWILIO_*`, `SMTP_PASS` for CAPTCHA alerts — run `npm run railway:provision-notifications -- --redeploy`.

| Task | Command |

| Full diagnose | `npm run railway:diagnose` |

## Migrating from Render

1. Complete Railway setup above and verify `/health` + `/ready`
2. Update Cursor MCP URL to the Railway domain (`npm run setup:cursor-mcp -- https://...`)
3. Run `npm run github:sync-secrets -- --apply` (sets `RAILWAY_URL` for GitHub Actions)
4. **Disable Render** in the Render dashboard (or delete the service) — the repo no longer runs a keepalive cron for Render

The old Render URL (`cdp-agent-0-01.onrender.com`) can be decommissioned once Railway is verified.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| CDP facilitator 401 on boot | Re-paste `CDP_API_KEY` and `CDP_PRIVATE_KEY` in Railway Variables (no stray spaces; PEM as single line with `\\n`) |
| MCP returns 401 with key | Redeploy after setting `MCP_API_KEY`: `npm run railway:sync-mcp-key` |
| Stuck Railway deploy (APPLYING) | `npm run railway:staged-fix -- --apply` |
| Postgres connection errors | Ensure Postgres service is named `Postgres` and `railway:provision` has been run |
